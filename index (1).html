インストール

必要なソフトを、上から順番に1つずつインストールしてください。焦らず、番号どおりに進めれば大丈夫です。

初めての方へ： 下の「①→②→③」の順に進めてください。1つ終わってから次に進むのがコツです。

① WinRAR（解凍ソフト）をインストール

ダウンロードしたファイルを開くために必要なソフトです。最初に入れておきます。

WinRAR をダウンロード
  1. 上のボタンをクリックして、WinRARのダウンロードページを開きます。
  2. 自分のパソコンに合ったもの（ほとんどの方は64ビット版）をダウンロードします。
  3. ダウンロードしたファイルをダブルクリックして開きます。
  4. 「インストール」ボタンを押し、そのまま「OK」「完了」を押して終わりです。

② DirectX をインストール

ゲームやツールを動かすために必要な部品です。

DirectX をダウンロード
  1. 上のボタンからページを開き、赤い「ダウンロード」ボタンを押します。
  2. ダウンロードしたファイルをダブルクリックして開きます。
  3. 「同意します」にチェックを入れて「次へ」を押します。
  4. 「Bing バーをインストールする」のチェックは必ず外してください。（不要なソフトが入るのを防ぐためです）
  5. そのまま「次へ」「完了」を押してインストールします。
「Bing バーをインストールする」のチェックを外し忘れないよう注意してください。

③ Visual C++ ランタイム（オールインワン）をインストール

ツールを正しく動かすために必要な部品をまとめて入れます。

Visual C++ ランタイムをダウンロード
  1. 上のボタンからページを開きます。
  2. ページの一番右上にあるファイルをクリックしてダウンロードします。
  3. ダウンロードした.zipファイルを右クリックし、「ここに展開（解凍）」を選びます。（①で入れたWinRARが使えます）
  4. 解凍してできたフォルダーを開きます。
  5. 中にある install_all.bat を右クリックし、「管理者として実行」を選びます。
  6. 黒い画面が出て自動で進みます。画面が閉じるまでそのまま待てば完了です。
「管理者として実行」を選ばないと正しくインストールされません。必ず右クリック → 管理者として実行で行ってください。

Windows Defenderを無効

次に、Windows Defender（Windows標準のウイルス対策）を無効にします。手順は2段階です。まず「リアルタイム保護」をオフにし、そのあと専用ツールで完全に無効化します。

STEP 1　先にリアルタイム保護をオフにする

専用ツールをダウンロードする前に、まずこの設定をオフにしておきます。

  1. スタートメニューを開き、「Windows セキュリティ」と入力して開きます。
  2. 「ウイルスと脅威の防止」をクリックします。
  3. 「ウイルスと脅威の防止の設定」の下にある「設定の管理」をクリックします。
  4. 「リアルタイム保護」のスイッチをオフにします。
  5. 「はい」と聞かれたら「はい」を押します。（あわせて「改ざん防止」もオフにできればオフにしてください）

STEP 2　専用ツールで無効化する

Defender無効化ツールをダウンロード
  1. 上のボタンからファイルをダウンロードします。
  2. ダウンロードしたファイルを右クリックし、「WinRARで展開（解凍）」を選びます。
  3. 解凍時にパスワードを聞かれたら、sordum と入力します。
  4. 解凍してできたフォルダーを開き、中の .exe ファイルをダブルクリックして起動します。
  5. ツールの画面で「Disable（無効化）」のボタンを押します。表示が赤（無効）になれば完了です。
解凍パスワードは sordum です。小文字で入力してください。
Defenderがツールを削除しようとする場合は、STEP 1のリアルタイム保護が本当にオフになっているか、もう一度確認してください。

クリーンインストール

Windowsを最初からきれいに入れ直す手順です。先にUSBメモリを準備してから、本体のインストールに進みます。上から順番に進めれば大丈夫です。

この作業をするとPC内のデータはすべて消えます。大事なファイルは先に別の場所へバックアップしてください。

STEP 1　USBにインストールデータを入れる

まず使いたいWindowsのISOファイル（またはflash media）を下からダウンロードして、USBメモリに入れます。

Windows 10 v22H2 ja x64.iso Windows 10 v21H2 ja x64.iso Windows 11 v21H2 ja x64.iso

STEP 2　RUFUSでUSBを起動可能にする

ダウンロードしたISOを、RUFUSというソフトでUSBに書き込みます。これでUSBから起動できるようになります。やり方は下の動画を見てください。

STEP 3　インストールを始める

  1. 作成したUSBをPCに差します。
  2. 設定 ▶ 回復 ▶ 今すぐ再起動 を選びます。
  3. 「デバイスの使用」からUSBを選びます。

STEP 4　ドライブを完全に消去する

ここでディスクを一度まっさらにします。この作業をする前にUSBを抜いてください。

  1. USBを抜きます。
  2. Shift + F10 を押してコマンドプロンプト（黒い画面）を起動します。
  3. 下のコマンドを1行ずつ入力し、それぞれ Enter を押します。
diskpart list disk select disk 0 clean
  1. コマンドプロンプトを閉じます。
  2. インストール画面に戻り、表示されているパーティションをすべて削除します。
  3. 新規で作成し、すべてフォーマットします。
diskpart とフォーマットは USBを必ず抜いた状態で行ってください。差したままだとUSB側を消してしまうおそれがあります。

STEP 5　もう一度インストールする

ドライブを消し終わったら、一度インストールを終了します。そのあとUSBを差し直して、もう一度インストールを最初から進めてください。

STEP 6　Windowsセットアップ

  1. 画面の案内に沿ってセットアップを進めます。
  2. アカウントを作成する画面で、有線LANでつないでいる場合はLANケーブルを抜き、「アカウントの作成」を選びます。
  3. そのまま案内どおりに進めれば完了です。
ケーブルを抜くのは、Microsoftアカウントの強制ログインを避けてローカルアカウントを作るためです。Wi-Fiの場合は接続しないまま進めてください。

BIOS FLASH

マザーボードのBIOS（UEFI）を最新版に更新する手順です。メーカーごとにやり方が違うので、下のタブから自分のマザーボードのメーカーを選んでください。

更新中は絶対に電源を切らないでください。途中で止まるとマザーボードが起動しなくなることがあります。ノートPCはバッテリー、デスクトップは安定した電源で行ってください。
ASUS
MSI
GIGABYTE
ASRock

ASUS（EZ Flash）

  1. ASUS公式サイトで自分のマザーボードの型番を検索し、「サポート」→「ドライバーとツール」からBIOSファイルをダウンロードします。
  2. .zip を解凍し、中の .CAP ファイルをUSBメモリ（FAT32形式）の直下にコピーします。
  3. USBを差してPCを起動し、起動直後に Delete または F2 を連打してBIOSに入ります。
  4. 「Advanced Mode（F7）」→「Tool」→「ASUS EZ Flash Utility」を開きます。
  5. USB内の .CAP ファイルを選び、更新を実行します。完了後は自動で再起動します。
CPUが無くても更新できる「BIOS FlashBack」対応ボードなら、専用USBポートに差して背面のFlashBackボタンを押すだけで更新できます。

MSI（M-Flash）

  1. MSI公式サイトで型番を検索し、「サポート」→「BIOS」から最新版をダウンロードします。
  2. 解凍したファイルをUSBメモリ（FAT32形式）の直下にコピーします。
  3. PCを起動し、Delete を連打してBIOSに入ります。
  4. 画面の「M-FLASH」ボタンを押し、「はい」で再起動します。
  5. USB内のBIOSファイルを選び、更新を実行します。完了まで待てば自動で再起動します。
「Flash BIOS Button」対応ボードは、ファイル名を指定の名前にリネームしてUSBに入れ、背面ボタンを押すだけで更新できます（詳細は各製品マニュアル参照）。

GIGABYTE（Q-Flash）

  1. GIGABYTE公式サイトで型番を検索し、「サポート」→「BIOS」から最新版をダウンロードします。
  2. 解凍したファイルをUSBメモリ（FAT32形式）の直下にコピーします。
  3. PCを起動し、Delete を連打してBIOSに入ります。
  4. F8 を押すか、画面の「Q-Flash」を選んで起動します。
  5. 「Update BIOS」→ USB内のファイルを選び、更新を実行します。完了後は自動で再起動します。
「Q-Flash Plus」対応ボードは、専用ポートにUSBを差してボタンを押すだけでCPUなしでも更新できます。

ASRock（Instant Flash）

  1. ASRock公式サイトで型番を検索し、「サポート」→「BIOS」から最新版をダウンロードします。
  2. 解凍したファイルをUSBメモリ（FAT32形式）の直下にコピーします。
  3. PCを起動し、F2 または Delete を連打してBIOSに入ります。
  4. 「Tool」→「Instant Flash」を選びます。USB内のBIOSファイルが自動で検出されます。
  5. 検出されたファイルを選び、更新を実行します。完了後は自動で再起動します。
「BIOS Flashback」対応ボードは、背面の専用ポートにUSBを差してボタンを押すだけでCPUなしでも更新できます。
